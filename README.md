# Design Vault

Public home for Coneyl Taylor's research studies and supporting files, published alongside their Zenodo records.

## What this is for

This repository holds finished materials that need a stable, citable, publicly accessible link — the kind a Zenodo record or a paper can point to and expect to keep working. It is not a working folder or a sketchbook; files land here once a study is ready to be referenced from outside.

## What's inside

- **[studies/](studies/)** — self-contained research studies, each in its own subfolder with its working file(s) and a README explaining what it tests and what it found. Covers both 3D work (Blender rigs, in Auto-Rig Pro) and, as it grows, graphic design studies.
